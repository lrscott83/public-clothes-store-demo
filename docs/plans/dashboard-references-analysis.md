# Análisis de Dashboards de Referencia

> Relevamiento de 14 dashboards de ejemplo (imágenes) para definir qué dashboards
> necesitamos construir. Para cada uno se documenta **qué muestra** (KPIs +
> visuales) y **qué filtros** ofrece.

## 1. Europe Bike Sales Dashboard
**Herramienta / estilo:** Power BI, tema oscuro (teal/magenta).

**Qué muestra:**
- **KPIs:** Total Revenue $85M · Total Profits $32M · % Profit 38% · Total Orders 1M.
- Ingresos y ganancias por año (barras, 2011-2016).
- Ingresos vs ganancias mensual (área).
- Ingresos/ganancias por país (barras).
- Género (dona F/M).
- Ingreso diario (área, días 1-30).
- Categorías de producto (dona: Bikes / Accessories / Clothing).
- Grupos de edad (barras).
- Top 5 subcategorías (treemap).

**Filtros:** Country · State · Year · Month (desplegables) + botonera de país a la izquierda (Australia, Canadá, Francia, Alemania, UK, USA).

## Patrones comunes (para definir los nuestros)

- **Fila de KPIs arriba** en casi todos: Revenue, Profit, Orders, Quantity, % Margen — muchos con **comparativa** (vs año/mes anterior, vs target).
- **Filtros típicos:** Fecha / Año / Mes / Trimestre · País / Región / Ciudad · Categoría / Producto · Cliente / Canal / Vendedor.
- **Visuales recurrentes:**
  - Tendencia temporal (línea / área / barras).
  - Distribución (dona / pie).
  - Ranking (barras horizontales, top N).
  - Geografía (mapa).
  - Tabla de detalle (con formato condicional).
- **Dos enfoques diferenciados:**
  - **Financiero:** revenue / profit / cost / margen.
  - **Actividad / operación:** llamadas, emails, horas, issues, días de inventario/cobro.
