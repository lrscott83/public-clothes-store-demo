# 06 — Requisitos del MVP

Características pedidas para un **desarrollo rápido** y con **pasos por tareas simples**.

## Restricciones

- **Sin autenticación ni autorización.**
- **Datos guardados en el navegador web** (localStorage). Sin backend.
- Usa los **productos del mismo store de electrodomésticos** (catálogo existente).

## Datos que el demo debe generar (sembrados)

- **Ventas de los últimos 20 días** en distintas monedas, con comisiones, etc., para poder
  mostrar el **dashboard de decisiones** y el **dashboard de finanzas**.
- **Inventario** de esos productos, disponibles y no disponibles, en los **3 almacenes**.
- Todo lo necesario para ejecutar **el proceso completo** con pasos sencillos.

## Experiencia

- Varias **vistas guiadas paso a paso** (tipo wizard / tour del nuevo proceso) para mostrar
  todo el flujo, por tipo de usuario.

## Principio de trabajo

- **No asumir nada.** Ante cualquier duda, preguntar antes de decidir.

## Alcance del entregable

- Todo el material de planificación se guarda en **`docs/plans/`** para conservarlo y actualizarlo.
