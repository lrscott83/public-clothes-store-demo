# 03 — Formato de pedido (actual)

Este es el formato de texto que los gestores completan hoy para enviar un pedido por WhatsApp.
El MVP lo reemplaza con formularios digitales, pero conserva los mismos campos.

## Campos

**Producto / venta**
- Producto
- Cantidad
- Total
- Forma de pago
- ¿Hay que llevar cambio?

**Cliente / entrega**
- Cliente
- Teléfono
- Dirección
- Domicilio (sí / no — domicilio vs. recogida en almacén)

**Observaciones**
- Observaciones

**Gestor / venta**
- Tipo de venta
- Nombre del gestor
- Teléfono (del gestor)
- Comisión
- Tarjeta

## Plantilla original (textual)

```
Producto:
Cantidad:
Total:
Forma de pago:
¿Hay que llevar cambio?:

Cliente:
Teléfono:
Dirección:
Domicilio:

Observaciones:

Tipo de venta:
Nombre del gestor:
Teléfono:
Comisión:
Tarjeta:
```
